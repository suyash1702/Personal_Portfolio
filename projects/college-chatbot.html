College Chatbot (ML & NLP)

Tech: Python, NLTK, scikit-learn, Jupyter Notebook, Flask (optional)

The College Chatbot demonstrates a full NLP pipeline for intent classification and response selection. It includes preprocessing, training multiple machine learning classifiers, evaluating models, and deploying a simple Flask web interface for interaction.

Methodology

  • Data preprocessing and augmentation (synonym replacement)
  • Train and evaluate multiple classification models to select the best
  • Use a trained model to predict user intent and serve a response from intent templates

Run locally (short)

git clone https://github.com/suyash1702/College-Chatbot-Using-ML-and-NLP-main.git
cd College-Chatbot-Using-ML-and-NLP-main
pip install -r requirements.txt
# or: pip install nltk scikit-learn flask
python app.py
