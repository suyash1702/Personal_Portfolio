Certificate Generator & Sender

Repo: Certificate_Generator_and_Sender

What it does

Generates personalized certificates from a Canva template using recipient data from an Excel sheet. Optionally prepared for automated emailing.

Prerequisites

  • Python 3
  • pandas, pillow, openpyxl (pip install pandas pillow openpyxl)
  • Place Shelley Script font in fonts/ if required by template

Quick Usage

git clone https://github.com/suyash1702/Certificate_Generator_and_Sender.git
cd Certificate_Generator_and_Sender
pip install pandas pillow openpyxl
python generate_certificates.py

Certificates will be saved to the certificates/ folder.
