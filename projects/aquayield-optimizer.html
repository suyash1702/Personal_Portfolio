AquaYield-Optimizer

Tech: JavaScript, Node.js, Data Visualization

AquaYield-Optimizer is an agriculture-focused web tool aimed at helping users estimate and optimize crop yields and irrigation parameters. It includes interactive simulations and visualization components to explore scenarios.

Key Features

  • Interactive simulation UI for parameter tuning
  • Data visualization of yield forecasts
  • Modular frontend components for experiment-driven UI

Quick start

git clone https://github.com/suyash1702/AquaYield-Optimizer.git
cd AquaYield-Optimizer
npm install
npm run dev
