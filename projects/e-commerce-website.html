Modern full-stack e-commerce application built with React + Vite + TypeScript, styled with Tailwind + shadcn-ui, and backed by Supabase (Postgres + Auth).

Live Demo

https://e-commerce-website-02w5.onrender.com

Quick Setup

git clone https://github.com/suyash1702/E-Commerce-Website.git
cd E-Commerce-Website
npm install
# create .env or .env.local with VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY
npm run dev

Notes

  • Requires a Supabase project for Auth and Postgres.
  • SQL files are included for initial schema and RLS policies.
  • Deployment: build with npm run build and set env vars on host.
E-Commerce Website - Project

E-Commerce Website

Tech: React + Vite + TypeScript, Tailwind CSS, Supabase (Postgres + Auth)

Trend Focus is a modern full-stack e-commerce web application built with React, Vite, TypeScript and backed by Supabase. It demonstrates a production-style feature set including authentication, product catalog, cart and order flows.

Key Features

  • User authentication with Supabase Auth (signup/login)
  • Product catalog with list & detail views and search
  • Shopping cart with persistent state and checkout flow
  • Inventory management backed by Supabase (Postgres)
  • Responsive UI built with Tailwind CSS and shadcn-ui components

Run locally (short)

git clone https://github.com/suyash1702/E-Commerce-Website.git
  cd E-Commerce-Website
  npm install
  # configure Supabase env vars (.env)
  npm run dev
