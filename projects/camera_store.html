Camera Store

Repo: Camera_Store

MERN-style e-commerce frontend and backend demo for a camera store; React frontend with Node/Express backend and MongoDB. Includes product grids, hero banners, and promo sections.

Quick Setup

git clone https://github.com/suyash1702/Camera_Store.git
cd Camera_Store
npm install
# or run provided install scripts: npm run install-server && npm run install-client
npm run dev

Notes

  • Backend expects a MongoDB URI in backend/.env.
  • Run MongoDB locally or use Atlas, then start backend and frontend.
  • Frontend default: http://localhost:3000 · Backend: http://localhost:5000
