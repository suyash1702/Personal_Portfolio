Health Challenge Tracker

Repo: health-challenge-tracker-master

Angular-based app to track workouts with search, filtering, pagination and charts. Includes unit tests and Firebase hosting demo.

Quick Setup

git clone https://github.com/suyash1702/health-challenge-tracker-master.git
cd health-challenge-tracker-master
npm install
ng serve
