Certificate Generator & Sender

Tech: Python, pandas, Pillow, openpyxl (Excel), optional SMTP

This project automates generating participation certificates from a Canva-designed template using recipient data from an Excel sheet. It inserts names/events into the template and saves personalized certificate images.

Key Features

  • Read recipient data from an Excel (`students.xlsx`)
  • Dynamically render name & event onto a certificate template (Shelley Script font)
  • Save generated certificates to `certificates/` directory
  • Optional: SMTP email sending (coming soon in repo)

Quick start

pip install pandas pillow openpyxl
python generate_certificates.py
